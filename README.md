# Operand

Jeu de calcul : fais rebondir les bulles jusqu'à l'opérateur et fabrique une brique égale à l'objectif.
Jouable sur https://hugohismans.github.io/addGame/ (le dépôt garde son nom d'origine).

Math game: bounce the bubbles onto the operator and build a brick equal to the goal. Available in French and English
(asked on the first visit, then FR / EN at the top right of the home screen; `?lang=en` or `?lang=fr` in the link forces it).
